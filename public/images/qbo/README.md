# QuickBooks / Intuit logos: drop folder

Put the official files here. No logo is drawn or invented in code.

| File name | What | Used on |
| --- | --- | --- |
| `quickbooks-logo.png` (or .svg) | Full-colour horizontal QuickBooks logo (green mark + wordmark) | Connect card, reports, comparison headers |
| `quickbooks-logo-white.png` | White / reversed version | Dark headers, PDF band |
| `quickbooks-mark.png` | Green round "qb" symbol on its own | Badges, tracker rows, small chips (min 16px) |
| `intuit-logo.png` | Intuit wordmark | Replica Intuit sign-in / consent screens |
| `connect-to-quickbooks.png` (+ `-hover`) | Official "Connect to QuickBooks" button | Connect step |
| `sign-in-with-xero.svg` (optional, can live in `../xero/`) | Official "Sign in with Xero" button | Platform login screen |

Official sources: Intuit developer "Naming and logo guidelines" page, and Xero's Brandfolder.
